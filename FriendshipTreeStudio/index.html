1. Sync with ChatGPTExports the current active source, Project DNA, architecture and diagnostics as one ZIP.
2. Install returned updateDrop the returned .ftupdate into the Seamless Update Centre above. App updates are backed up and applied transactionally.
3. Build and deployBuilds the web app, syncs Capacitor, creates the APK and installs it over USB or wireless ADB.
4. Free remote deliveryCopies the APK and checksum into a Google Drive or other synced folder so it can be downloaded on your phone.
